# Руководства

Практико-ориентированные рецепты и интеграции для DWE. Каждая страница решает конкретную пользовательскую задачу («как подключить DWE к промту шелла?», «как встроить DWE в CI?») вместо описания одной команды или одного поля конфига.

Руководства соседствуют со [справочником](../reference/index.md) (схемы, поверхность команд, шаблонизатор) — справочник отвечает на вопрос *что есть*, руководства — *как это использовать вместе*.

## Страницы

- [Интеграция со Starship](starship.md) — компактный, проектно-ориентированный сегмент DWE внутри промта [Starship](https://starship.rs/).

## См. также

- [Справочник (`reference/`)](../reference/index.md) — схемы, поля конфига, render-паки, подсистема документации
- Запустите `dwe --help` (или любую подкоманду с `--help`), чтобы увидеть актуальный CLI-интерфейс
- Запустите `dwe docs` для интерактивного браузера по всему дереву документации
