# Интерактивный TUI-браузер

`dwe docs` открывает интерактивный терминальный интерфейс для просмотра всей документации.

## Использование

```bash
dwe docs [--lang <code>]
```

`--lang` заранее выбирает локаль, с которой откроется браузер (по умолчанию: активная локаль или `en`); `L` по-прежнему переключает языки прямо в сессии.

## Требования

- TTY (терминал) — для неинтерактивного использования (пайпы, агенты) применяйте [`dwe docs show <topic>`](commands.md#dwe-docs-show-topic) или [`dwe docs list`](commands.md#dwe-docs-list) вместо этого.

## Навигация

| Клавиша | Действие |
|---------|----------|
| `j` / `↓`, `k` / `↑` | Вниз/вверх |
| `h` / `←` | Свернуть выделенную папку либо перейти к её родителю, если она уже свёрнута |
| `l` / `→` | Развернуть выделенную папку либо перейти к её первому потомку, если она уже развёрнута |
| `f` / `PgDn`, `b` / `PgUp` | Страница вниз/вверх в панели содержимого |
| `g`, `G` | Перейти в начало/конец |
| `Tab` / `Shift+Tab` | Циклически переключать фокус вперёд/назад между деревом (слева) и содержимым (справа) |
| `Enter` | Открыть тему |
| `/` | Фильтр дерева по подстроке (нечувствительный к регистру поиск по именам каталогов, заголовкам файлов и заголовкам разделов) |
| `]`, `[` | Перейти к следующей/предыдущей mermaid-диаграмме |
| `o` | Открыть выделенную mermaid-диаграмму в системном просмотрщике |
| `y` | Скопировать исходник mermaid через буфер обмена (OSC 52) |
| `L` | Циклически переключать доступные языки для текущей темы |
| `e` | Перейти к английскому оригиналу (при просмотре перевода) |
| `Ctrl+R` | Перезагрузить текущую тему (подхватывает изменения в проектных доках на лету) |
| `?` | Показать модальное окно с клавишами, активными в текущем режиме |
| `q` / `Esc` / `Ctrl+C` | Выход |

Нажмите `?`, чтобы открыть модальное окно справки, сгенерированное из биндингов, активных в текущем режиме, — оно перечисляет ровно те клавиши, что выше, не занимая постоянный подвал.

## Мышь

Браузер также реагирует на мышь:

- **Одиночный клик** по строке дерева перемещает курсор туда и фокусирует панель.
- **Двойной клик** по строке дерева открывает её (как `Enter`).
- **Колесо** прокручивает панель под указателем (дерево тем или вьюпорт содержимого), не меняя фокус.
- **Клик** по подсказке `? help` открывает модальное окно справки.

## Раскладка

- **Левая панель:** свёртываемое дерево всех тем (встроенные доки DWE и проектные доки, если есть)
- **Правая панель:** отрендеренный markdown с подсветкой синтаксиса
- **Статусная строка:** путь текущей темы, прогресс mermaid, активный язык и подсказки клавиш
