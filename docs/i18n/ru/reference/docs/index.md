# Подсистема документации

Devbox включает встроенный браузер документации и справочную систему. Доступ ко встроенным докам, проектным докам (когда они есть), рендер markdown с подсветкой синтаксиса и просмотр mermaid-диаграмм прямо на месте.

- [Неинтерактивные команды](commands.md) — `show`, `list`, `export`, `llms-txt`, `cache clear`, а также настройка mermaid и установка `mmdc`

## Быстрый старт

Просмотр доков в интерактивном режиме:
```bash
devbox docs
```

Показ конкретной темы в терминале:
```bash
devbox docs show config/services/fields
devbox docs show config/devbox#binary-overrides
```

Список всех доступных тем:
```bash
devbox docs list
```

Экспорт всех доков в каталог:
```bash
devbox docs export ./my-docs
```

## Проектные доки

Devbox автоматически обнаруживает и подключает документацию из каталога `./docs/` вашего проекта.

Когда `./docs/` существует, TUI-браузер показывает вторую верхнеуровневую ветку:
```
Devbox
  reference/
  internals/
Project
  guides/
  examples/
```

Если `./docs/` отсутствует или пуст, ветка Project опускается.

**Структура:**
```
<project>/
  docs/
    guides/
      setup.md
    examples/
      docker.md
    README.md
```

**Горячая перезагрузка:** правьте файлы в `./docs/`, пока TUI открыт — viewport обновится автоматически (нажмите `r` для ручного обновления, если автоопределение пропустит правку).

## Справочник конфигурации

### `binaries.mmdc`

Путь или имя исполняемого файла mermaid-cli. По умолчанию `mmdc` (ищется в `$PATH`).

```yaml
binaries:
  mmdc: /usr/local/bin/mmdc   # абсолютный путь
  mmdc: mmdc                   # имя в $PATH (по умолчанию)
```

### `docs.mermaid`

Режим рендера mermaid. Одно из:
- `auto` — рендер, если `mmdc` доступен; иначе fallback на сырой блок (по умолчанию)
- `mmdc` — требовать `mmdc`; плашка-плейсхолдер, если он не найден
- `off` — никогда не рендерить; всегда показывать сырые mermaid-блоки

По умолчанию: `auto`

```yaml
docs:
  mermaid: auto   # по умолчанию
  mermaid: mmdc   # строгий режим
  mermaid: off    # выключено
```

### `docs.cache_size_mb`

Максимальный размер кеша mermaid-диаграмм в МБ. По умолчанию `100`.

```yaml
docs:
  cache_size_mb: 50   # 50 МБ кеша
  cache_size_mb: 500  # 500 МБ кеша
```

Когда кеш превышает лимит, самые старые диаграммы удаляются автоматически (вытеснение по LRU).

## Связанные команды

- `devbox docs generate` — сгенерировать markdown-документацию из пользовательских команд
- `devbox validate` — проверить документацию на ошибки и осиротевшие записи переводов
- `devbox command list` — вывести пользовательские команды с переведёнными описаниями
