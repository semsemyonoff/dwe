## devbox tools

Toggle tools (interactive) or enable/disable individually

### Synopsis

Open an interactive multi-select form to enable or disable optional tools.

Changes are written to devbox/local.yml and .env is regenerated.
Use 'devbox run' to start newly enabled tools.

For a read-only view, run 'devbox status tools'.

```
devbox tools [flags]
```
